# Pamugas

Freelancer & Agency Operations Portal for Filipino digital agencies specializing in SEO, content, and paid ads.

## Key Features
- **Timezone-Aware Approvals**: Seamless coordination between Asia/Manila (PHT) and global client timezones (EST, PST, GMT, AEST, etc.).
- **Contract Management**: Scope of work, deliverables tracking, sign-off status, and terms.
- **Dual-Currency Billing (PHP / USD)**: Automated dual-currency invoicing, real-time FX conversion, and payment tracking.
- **Client & Deliverable Portal**: Interactive client-facing dashboard and agency admin operations.
